# 记账本（jizhang）

离线优先的家庭记账 App（PWA）：

- **手机**：Chrome 打开网页 → 菜单"安装应用"→ 独立图标全屏运行，**断网、电脑关机都能记账**
- **电脑**：同一网址，浏览器直接用
- **同步**：数据先存本机（IndexedDB），联网时自动通过 **GitHub 私有 Gist** 在设备间双向同步（后记的账两边都能看到）
- **备份**：本机一份 + GitHub 一份，电脑格式化也不怕丢

## 网址

<https://xq1125.github.io/jizhang/>

## 首次使用（两台设备各做一次）

1. 打开上面的网址（手机第一次建议用 **Chrome**）
2. 手机：菜单 ⋮ → **安装应用 / 添加到主屏幕**；电脑：地址栏右侧的安装图标，或菜单 → 应用 → 安装
3. 进 App → **设置** → 按页面里的链接到 GitHub 生成一个只勾选 **gist** 的 Token（classic token），粘贴保存
4. 点"立即同步"：第一台设备会自动创建云端账本；第二台设备填**同一个 Token** 就会自动连上同一个账本

不填 Token 也能用，只是数据只存在这一台设备上。

## 功能

- **记一笔**：支出/收入、金额、分类（可自定义）、日期、备注
- **明细**：按天分组，点记录可修改/删除（删除也会同步到其他设备）
- **统计**：月度收支结余、分类占比饼图、每日收支柱状图
- **设置**：同步状态、Token 管理、手动同步
- 顶栏小圆点：绿=已同步，黄=待同步/同步中，红=失败（会自动重试）

## 同步原理（简述）

每条记录带时间戳，存在本机 IndexedDB；每次改动后约 4 秒，App 把本机数据与
GitHub 私有 Gist（`jizhang-ledger.json`）双向合并（同一记录谁的更新时间新听谁的），
再写回 Gist。Gist 是私有的，只有你的 GitHub 账号可见。

## 旧版局域网模式（可选备用）

`lan/` 目录保留了最早"电脑跑 Python 服务、手机连 Wi-Fi"的版本（含说明），
现在**不需要开机自启它**；想彻底停用可删除开始菜单"启动"文件夹里的
`记账本-自动启动.bat`（Win+R 输入 `shell:startup`）。
