# 记账本（jizhang）

一个零依赖的家庭记账小软件：电脑上跑一个 Python 小服务，
- **电脑**：浏览器打开网页版（也可以把网页“安装”成桌面应用）
- **手机**：连同一个 Wi-Fi，打开网页后“添加到主屏幕”，全屏运行，像个 App
- 两端数据实时共享，全部存在电脑本地的 SQLite 数据库里

## 快速开始（电脑）

1. 双击 **`启动记账.bat`**
   - 会弹出一个黑色服务窗口（`JiZhang Server`），**保持它开着**就是在使用
   - 浏览器自动打开 <http://localhost:8765>
2. 第一次运行时 Windows 防火墙可能弹窗，请勾选 **“专用网络”** 并点 **“允许访问”**
   （不允的话手机连不上）

停止：关闭那个黑色服务窗口即可。数据不会丢。

## 手机设置（Android / iPhone 通用）

1. 手机和电脑连**同一个 Wi-Fi**
2. 看服务窗口里打印的地址，形如 `http://192.168.x.x:8765`，在手机浏览器输入它
3. 添加到主屏幕：
   - **iPhone（Safari）**：分享按钮 → “添加到主屏幕”
   - **Android（Chrome/Edge）**：菜单 ⋮ → “添加到主屏幕”/“安装应用”
4. 以后点桌面图标就是全屏的“记账本”App，记的账立刻同步到电脑

> 说明：手机走的是局域网 http 地址，不是真正的“离线 App”——它需要电脑开着服务。
> 电脑关机时手机就打不开，这是本方案（数据存电脑）的正常现象。

## 功能

- **记一笔**：支出/收入、金额、分类（可自己加）、日期、备注
- **明细**：按天分组，点一条记录可以修改或删除
- **统计**：月度收支汇总、支出分类占比饼图、每日收支柱状图
- **按月翻查**：顶部 ‹ › 切换月份

## 数据在哪？怎么备份？

全部在 `data\ledger.db`（单个文件）。复制这个文件就是完整备份；
想恢复时把它放回去、重启服务即可。

## GitHub 自动备份（防电脑丢失）

代码仓库：<https://github.com/xq1125/jizhang>（**私有仓库**，只有你的账号能看）

- **每记一笔账，约 8 秒后服务会自动把账本快照（`backups/ledger.db`）提交并推送到 GitHub**，无需手动操作；断网/关机时会在服务窗口提示失败并自动重试
- 手机记的账同样自动备份（都是经过电脑上的服务）
- 想关掉自动备份：新建环境变量 `JIZHANG_AUTO_BACKUP=0`
- 程序代码改动后仍需手动 `git add -A && git commit && git push`

### 电脑重装/格式化后如何恢复

1. 安装 Git 和 Python 3（python.org，勾选 Add to PATH），`gh auth login` 或 git 凭据登录你的 GitHub
2. `git clone https://github.com/xq1125/jizhang.git`
3. 直接启动服务即可：**服务发现本地没有账本时，会自动从仓库里的 `backups\ledger.db` 还原**
4. 修改 `启动记账.bat` 里的 Python 路径（或直接用 `python server.py` 启动）

## 常见问题

| 现象 | 处理 |
|---|---|
| 手机打不开 `http://192.168.x.x:8765` | 确认手机和电脑在同一 Wi-Fi；确认防火墙弹窗点了允许；路由器开了“AP 隔离”的话要关掉 |
| 端口被占用 / 启动报错 | 换个端口：新建环境变量 `JIZHANG_PORT=9000`，或编辑 `server.py` 里的默认端口 |
| 电脑 IP 变了，手机连不上 | 服务窗口每次会打印当前 IP，重新输入即可；在路由器里给电脑绑定固定 IP 更省心 |
| 双击 bat 闪退 | 电脑可能没装 Python 3；到 python.org 安装时勾选 “Add to PATH” |

## 想开机自动启动？（可选）

`Win + R` 输入 `shell:startup` 回车，把 `启动记账.bat` 的快捷方式放进去。

## 目录结构

```
jizhang/
├── server.py          # 后端：标准库 HTTP 服务 + SQLite，无任何第三方依赖
├── 启动记账.bat        # 一键启动
├── data/ledger.db     # 数据库（自动生成）
└── web/               # 前端（纯静态，无 CDN 依赖）
    ├── index.html / style.css / app.js
    ├── manifest.webmanifest / sw.js   # PWA：可安装、可缓存外壳
    └── icons/         # 应用图标
```
